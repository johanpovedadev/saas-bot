## 🎯 Guías de Lectura Rápida

2. Ver screenshots en `screenshots/` (3 min)
3. Revisar **TECHNICAL_CHALLENGES.md** - Reto #3 (2 min)

1. Leer **EXECUTIVE_SUMMARY.md** (5 min)
2. Revisar **ARCHITECTURE.md** (15 min)
3. Ver **PERFORMANCE_METRICS.md** (10 min)

## 🔧 Recursos Adicionales

### **Diagramas de Arquitectura (Mermaid.js):**
Todos los diagramas están en formato `.mmd` y se renderizan automáticamente en GitHub.

Para visualizarlos localmente:
- Online: [Mermaid Live Editor](https://mermaid.live/)

Capturas de pantalla del bot en acción. Ver `screenshots/README.md` para guía.

### **Benchmarks:**
Resultados de pruebas de carga y performance. Ver `benchmarks/` para detalles.
