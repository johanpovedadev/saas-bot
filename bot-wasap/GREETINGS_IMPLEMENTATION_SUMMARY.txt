┌──────────────────────────────────────────────────────────────────────────────┐
│ 🧠 LÓGICA INTELIGENTE                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  1️⃣  NORMALIZACIÓN DE TEXTO
      ─────────────────────────
      • Ignora tildes (á → a, é → e)
      • Ignora mayúsculas/minúsculas
      • Ignora puntuación (¿?¡!.,;:)
      • Trim de espacios

      Ejemplo: "¿Qué más, pues?" → "que mas pues"

  2️⃣  DETECCIÓN INTELIGENTE
      ────────────────────────
      • Coincidencia exacta: "hola" = "hola"
      • Al inicio: "hola amigo" = saludo + mensaje
      • Al final: "pues hola" = mensaje + saludo
      
  3️⃣  DIFERENCIACIÓN SOLO SALUDO vs SALUDO + PEDIDO
      ────────────────────────────────────────────────
      Solo saludo → Muestra menú completo
      • "hola"
      • "q mas"
      • "buenas"
      • "aja"
      
      Saludo + pedido → Detecta saludo pero NO muestra menú
      • "hola quiero una copa"
      • "q mas necesito helado"
      • "buenas, dame 2 litros"

  4️⃣  PRIORIZACIÓN REGIONAL
      ──────────────────────
      Se detecta primero saludos regionales (más específicos)
      luego los genéricos, para dar respuestas personalizadas.
