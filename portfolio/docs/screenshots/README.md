## 🛠️ Tips para Capturar Screenshots

### **Privacidad:**
- ✅ Difuminar números de teléfono reales
- ✅ Usar números de prueba (+57 300 123 4567)
- ✅ Evitar nombres de clientes reales

### **Calidad:**
- ✅ Resolución mínima: 1080x1920 (móvil) o 1920x1080 (desktop)
- ✅ Formato: PNG (mejor que JPG para texto)
- ✅ Modo claro (light mode) para mejor legibilidad

### **Herramientas:**
- **Windows:** Win + Shift + S (Snipping Tool)
- **WhatsApp Web:** Captura de pantalla del navegador
- **Anotaciones:** [Greenshot](https://getgreenshot.org/) o [ShareX](https://getsharex.com/)

## 📝 Template de Anotaciones

Para screenshots anotados, incluye:
1. ✅ Números o flechas señalando features clave
2. ✅ Texto explicativo breve
3. ✅ Círculos resaltando elementos importantes
4. ✅ Colores consistentes (ej: verde = éxito, rojo = error)
